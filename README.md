# แดชบอร์ดวิเคราะห์ตลาดแรงงานไทย (Thailand Labor Market Interactive Dashboard)

ระบบแดชบอร์ดวิเคราะห์สถิติตลาดแรงงานไทยแบบโต้ตอบ (Interactive Analytics Dashboard) พัฒนาด้วยภาษา **Python**, **Streamlit**, **Pandas** และ **Plotly** โดยใช้ข้อมูลสถิติภาวะการทำงานของประชากรจากสำนักงานสถิติแห่งชาติ (NSO) ระหว่างปี พ.ศ. 2555 – 2569

แดชบอร์ดนี้ออกแบบภายใต้แนวคิด **Modern Admin Bento Grid + Soft Pastel Gradient** (ชมพู-ม่วง-พาสเทล) พร้อมรองรับการคลิกเลือกข้อมูลบนกราฟเพื่อกรองข้อมูลร่วมกันข้ามชาร์ตแบบสองทิศทาง (**Bi-directional Cross-filtering**)

---

## ฟีเจอร์เด่นของระบบ

1. **ระบบ Cross-Filtering เชื่อมโยงข้ามชาร์ต:**
   - คลิกที่ชาร์ตภูมิภาค เพื่อกรองดูข้อมูลเฉพาะภาคนั้นในทุกมุมมอง
   - คลิกที่ชาร์ตเพศ เพื่อเปรียบเทียบข้อมูลเฉพาะชายหรือหญิง
   - คลิกที่ชาร์ตช่วงเวลา เพื่อเจาะจงปีหรือไตรมาสที่ต้องการ
   - ป้ายแสดงตัวกรองที่เลือก (Active Filter Tags) พร้อมปุ่มคลิกปิดตัวกรองทีละตัว
   - ปุ่ม **"รีเซ็ตตัวกรองทั้งหมด" (Reset All Filters)** ทำงานได้อย่างรวดเร็ว

2. **การคำนวณทางสถิติที่ถูกต้องตามหลักสถิติทางการ:**
   - ใช้อัตราส่วนและค่าเฉลี่ยที่ผ่านการถ่วงน้ำหนัก (Weighted Average) จากแถวผลรวมทางการ
   - ไม่มีการนำอัตราเปอร์เซ็นต์มาบวกกัน หรือหาค่าเฉลี่ยแบบผิดหลักสถิติ
   - จัดการมิติข้อมูลที่แตกต่างกันอย่างโปร่งใส พร้อมระบบแจ้งเตือนข้อจำกัดของข้อมูล

3. **งานออกแบบระดับมืออาชีพ (Bento Grid):**
   - ธีมสีชมพู-ม่วง-พาสเทล (`#E83C91`, `#843A7D`, `#43334C`, `#57C7FF`, `#F7A531`)
   - ใช้ฟอนต์ **Kanit** สำหรับข้อความภาษาไทย
   - การ์ดสถิติ KPI แสดงค่าจ้างเฉลี่ย, อัตราการมีงานทำ, อัตราการว่างงาน และจำนวนประชากรมีงานทำ

4. **แบ่งการวิเคราะห์ออกเป็น 4 แท็บหลัก:**
   - **แท็บ 1 — ภาพรวมตลาดแรงงานไทย:** แนวโน้มตามเวลา, ผลกระทบฤดูกาล และจำนวนผู้มีงานทำ
   - **แท็บ 2 — วิเคราะห์ตลาดแรงงานรายภูมิภาค:** การเปรียบเทียบรายภาค, แผนที่ Choropleth, ช่องว่างค่าจ้างใน/นอกเขตเทศบาล
   - **แท็บ 3 — วิเคราะห์กลุ่มประชากรและความแตกต่าง:** ช่องว่างค่าจ้างทางเพศ (Gender Wage Gap), การว่างงานของเยาวชน (Youth Unemployment), โครงสร้างค่าจ้างตามกลุ่มอายุ
   - **แท็บ 4 — ตารางข้อมูลและคำอธิบายสถิติ:** ตารางค้นหาข้อมูลและสรุปข้อจำกัดทางสถิติ

## วิธีติดตั้งและเริ่มต้นใช้งาน

### 1. การติดตั้ง Dependencies

เปิด Terminal หรือ PowerShell ภายในโฟลเดอร์โปรเจกต์ แล้วติดตั้งไลบรารีที่จำเป็น:

```bash
pip install -r requirements.txt
```

### 2. การรันแอปพลิเคชันแดชบอร์ด

รันคำสั่งมาตรฐานของ Streamlit:

```bash
python -m streamlit run app.py
```

เมื่อรันสำเร็จ เบราว์เซอร์จะเปิดแดชบอร์ดขึ้นมาที่ `http://localhost:8501` โดยอัตโนมัติ

### 3. การรันการทดสอบระบบ (Automated Tests)

```bash
python -m unittest discover -s tests
```

## ข้อมูลและข้อจำกัดสำคัญ (Data Caveats)

1. **หน่วยนับจำนวนผู้มีงานทำ (`emp_headcount`):** มีหน่วยเป็น **พันคน (Thousand Persons)**
2. **ข้อมูลค่าจ้างปี 2567-2568:** ถูกเผยแพร่เป็นค่ารวมทั้งปี (`quarter = 0`) ไม่สามารถแยกเป็นรายไตรมาสได้
3. **การเปลี่ยนแปลงระบบภูมิภาคในปี 2568:** สำนักงานสถิติแห่งชาติได้แยก `ภาคตะวันออก` ออกจากภาคกลาง และแยก `ภาคใต้ชายแดน` ออกจากภาคใต้ ทำให้ปี 2568 มี 7 ภูมิภาค (จากเดิม 5 ภูมิภาค)
4. **ตัวแปรที่ไม่มีในชุดข้อมูล:** ไม่มีตัวแปรประเภทอุตสาหกรรม (`industry`), ระดับการศึกษา (`education`) และจำนวนคนว่างงานเป็นตัวเลขคน — แดชบอร์ดจะระบุไว้อย่างชัดเจนและไม่มีการปั้นข้อมูลเท็จ
