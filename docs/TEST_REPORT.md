## 3. การทดสอบความถูกต้องของสถิติและการป้องกันข้อผิดพลาด (Statistical Integrity Tests)

1. **การป้องกันการบวกอัตราเปอร์เซ็นต์ซ้ำ (No Rate Summing):**
   - ตรวจสอบแล้วว่า `emp_rate` และ `unemp_rate` ดึงจากแถว `รวม` ของ สนง.สถิติแห่งชาติที่ผ่านการถ่วงน้ำหนักแล้ว ไม่มีการนำอัตราเปอร์เซ็นต์มาหาค่าเฉลี่ยทางคณิตศาสตร์แบบผิดหลักสถิติ
2. **การป้องกันการนับประชากรซ้ำ (Deduplicated Headcount):**
   - ตรวจสอบแล้วว่า `emp_headcount` ถูกตัดแถวซ้ำบน `(year, quarter, region, sex, age_group)` ทำให้ผลรวมประชากรทำงานของไทยอยู่ที่ ~38-40 ล้านคนถูกต้อง ตรงกับรายงานสถิติของ สนง.สถิติแห่งชาติ
3. **การจัดการค่าจ้างปี 2567-2568 (`quarter = 0`):**
   - เมื่อเลือกดูปี 2567 หรือ 2568 และเลือกไตรมาส 1–4 ระบบแสดงแบนเนอร์แจ้งเตือนอย่างโปร่งใสว่า "สถิติค่าจ้างปีนี้มีเฉพาะภาพรวมทั้งปี (ไตรมาส 0) ไม่สามารถแยกรายไตรมาสได้"
4. **การจัดการระบบ 5 ภูมิภาค และ 7 ภูมิภาค:**
   - เมื่อเลือกปีต่ำกว่า 2568 แดชบอร์ดแสดงผลตามระบบ 5 ภูมิภาคดั้งเดิม เมื่อเลือกปี 2568 แดชบอร์ดแสดงผลตามระบบ 7 ภูมิภาค (แยกภาคตะวันออกและภาคใต้ชายแดน)
