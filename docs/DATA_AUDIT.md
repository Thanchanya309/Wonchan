## 2. การวิเคราะห์มิติและหมวดหมู่ (Dimension Analysis & Normalization)

จากการสำรวจพบว่าชุดข้อมูลเกิดจากการนำตารางสถิติหลายตารางมารวมกัน ทำให้ชื่อหมวดหมู่ในบางปีมีตัวเลขลำดับหรือข้อความกำกับภาษาอังกฤษปนอยู่ ซึ่งต้องทำการปรับให้เป็นมาตรฐาน (Normalization):

### 2.1 มิติเพศ (`sex`)
- **ค่าเดิมที่พบ:** `ชาย`, `หญิง`, `รวม`, `1. ชาย`, `2. หญิง`
- **การปรับมาตรฐาน (`clean_sex`):** ตัดตัวเลขและจุดนำหน้า ได้เป็น 3 หมวดหมู่ชัดเจน:
  - `ชาย` (10,258 แถว)
  - `หญิง` (10,157 แถว)
  - `รวม` (9,115 แถว) — แถวผลรวมทางการถ่วงน้ำหนัก

### 2.2 มิติกลุ่มอายุ (`age_group`)
- **ค่าเดิมที่พบ:** `15-19 ปี` ถึง `60 ปีขึ้นไป`, `1. 15-19 ปี` ถึง `8. 60 ปีขึ้นไป`, `60 ขึ้นไป`, `รวม`, `Total`
- **การปรับมาตรฐาน (`clean_age`):** ตัดตัวเลขนำหน้า แปลง `60 ขึ้นไป` -> `60 ปีขึ้นไป` และ `Total` -> `รวม` ได้ 8 กลุ่มอายุมาตรฐาน + แถวผลรวม `รวม`:
  1. `15-19 ปี` (เยาวชนต้น)
  2. `20-24 ปี` (เยาวชนปลาย / เข้าสู่ตลาดแรงงาน)
  3. `25-29 ปี`
  4. `30-34 ปี`
  5. `35-39 ปี`
  6. `40-49 ปี`
  7. `50-59 ปี`
  8. `60 ปีขึ้นไป` (แรงงานสูงอายุ)
  9. `รวม` (ผลรวมทุกกลุ่มอายุ)

### 2.3 มิติพื้นที่เขตการปกครอง (`area`)
- **ค่าเดิมที่พบ:** `ในเขตเทศบาล`, `นอกเขตเทศบาล`, `รวม`, `1) ในเขตเทศบาล`, `1) เขตเทศบาล`, `2) นอกเขตเทศบาล`, `NaN` (2,800 แถว)
- **การปรับมาตรฐาน (`clean_area`):** รวมชื่อเข้าด้วยกัน:
  - `ในเขตเทศบาล` (Urban)
  - `นอกเขตเทศบาล` (Rural)
  - `รวม` (Total Area)
  - `NaN` / `ไม่ระบุ`: เกิดจากตาราง headcount ในปี 2555-2560 และ 2567-2569 ที่สำรวจในระดับภูมิภาคโดยไม่จำแนกพื้นที่เขตเทศบาล

### 2.4 มิติภูมิภาค (`region`) และการเปลี่ยนแปลงระบบสถิติ
- **ช่วงปี 2555 – 2567 (ระบบ 5 ภูมิภาค):**
  - กรุงเทพมหานคร
  - ภาคกลาง (รวมภาคตะวันออก)
  - ภาคเหนือ
  - ภาคตะวันออกเฉียงเหนือ
  - ภาคใต้ (รวมภาคใต้ชายแดน)
  - รวม (ผลรวมระดับประเทศ)
- **ช่วงปี 2568 – 2569 (ระบบ 7 ภูมิภาค):**
  - สนง.สถิติแห่งชาติได้แยกย่อยภูมิภาคเพิ่มขึ้น ได้แก่ `ภาคตะวันออก` (แยกจากภาคกลางเดิม) และ `ภาคใต้ชายแดน` (แยกจากภาคใต้เดิม)
- **แนวทางจัดการ:** แดชบอร์ดจะระบุไว้อย่างชัดเจนว่า ในปี 2568 ตัวเลขของภาคกลางและภาคใต้มีการปรับฐานนิยามใหม่ตามประกาศ สนง.สถิติแห่งชาติ

## 3. มิติเวลาและกรณี `quarter = 0`

- **ปี 2555–2566:** มีข้อมูลไตรมาส 1 ถึง 4 ปกติ (ไม่มี `quarter = 0`)
- **ปี 2567 และ 2568:**
  - มีข้อมูล `quarter = 0` รวม 3,699 แถว
  - ข้อมูลใน `quarter = 0` มีเฉพาะคอลัมน์ `avg_wage` เท่านั้น (ไม่มี `emp_rate`, `unemp_rate`, `emp_headcount`)
  - คอลัมน์ `emp_rate` และ `unemp_rate` ของปี 2567 และ 2568 มีเฉพาะในไตรมาส 1–4
- **ข้อสรุปและการจัดการ:**
  - `quarter = 0` คือข้อมูลสถิติค่าจ้างเฉลี่ยระดับ "ภาพรวมรายปี" (Annual Overview)
  - **ข้อกำหนด:** ห้ามนำค่าจ้างในไตรมาส 0 ไปรวมหรือเปรียบเทียบเทียบเท่ากับข้อมูลรายไตรมาส 1–4 และเมื่อผู้ใช้เลือกเจาะจงไตรมาส 1–4 ในปี 2567-2568 แดชบอร์ดจะต้องแจ้งเตือนอย่างซื่อตรงว่าค่าจ้างปีนี้มีเฉพาะค่าสรุปรายปี

## 4. จำนวนผู้มีงานทำ (`emp_headcount`) และการป้องกันการนับซ้ำ

- **หน่วยวัด:** `emp_headcount` มีหน่วยเป็น **พันคน (Thousand Persons)** (ตัวเลขประมาณ 37,000 – 40,000 พันคน หรือ 37 – 40 ล้านคน สอดคล้องกับประชากรผู้มีงานทำของประเทศไทย)
- **การตรวจพบข้อผิดพลาดจากการรวมข้อมูลดิบ (Data Merging Artifact):**
  - ในปี 2561–2566 ข้อมูล headcount ระดับภาคถูกทำสำเนาซ้ำลงในทุกแถวของ `area` (`ในเขตเทศบาล`, `นอกเขตเทศบาล`, `รวม`) ด้วยค่าตัวเลขเดียวกัน
  - **กฎการคำนวณ:** ห้ามนำคอลัมน์ `emp_headcount` มา `.sum()` ทั้งตารางโดยไม่กรอง เพราะจะทำให้ตัวเลขนับซ้ำถึง 3 เท่า
  - การคำนวณจำนวนผู้มีงานทำจะต้อง deduplicate บน `(year, quarter, region, sex, age_group)` เสมอ

## 5. การประเมินคำถามเชิงวิเคราะห์ (Analytical Question Assessment)

### 5.1 คำถามที่ตอบได้สมบูรณ์ (Fully Supported)
1. **แนวโน้มการเปลี่ยนแปลงตามเวลา:** อัตราการมีงานทำ, อัตราการว่างงาน และค่าจ้างเฉลี่ยข้ามปี พ.ศ. 2561–2568
2. **การเปรียบเทียบความแตกต่างระหว่างภูมิภาค:** ภูมิภาคใดมีอัตราว่างงานสูงสุด/ต่ำสุด และภูมิภาคใดมีค่าจ้างเฉลี่ยสูงสุด (กรุงเทพมหานครสูงสุด ~18,000–22,000 บาท, อีสานและใต้ต่ำสุด ~11,000–13,000 บาท)
3. **ความสัมพันธ์ระหว่างค่าจ้างและอัตราการมีงานทำ (Wage vs Employment Rate):** วิเคราะห์ผ่าน Scatter plot รายภาค
4. **ความแตกต่างตามฤดูกาล (Seasonality):** การผันผวนของแรงงานเกษตรระหว่างไตรมาส 3 (ฤดูทำนา) กับไตรมาส 1 (ฤดูแล้ง)
5. **ช่องว่างค่าจ้างระหว่างเพศ (Gender Wage Gap):** ค่าจ้างเฉลี่ยชายเทียบกับหญิงในแต่ละภูมิภาคและช่วงอายุ
6. **โครงสร้างค่าจ้างตามช่วงอายุ (Age-Wage Profile):** ช่วงอายุใดมีค่าจ้างสูงสุด (พีคที่ 40–49 ปี และ 50–59 ปี)
7. **ปัญหาการว่างงานของเยาวชน (Youth Unemployment):** อัตราการว่างงานกลุ่ม 15–19 และ 20–24 ปี สูงกว่าวัยอื่นอย่างมีนัยสำคัญ
8. **ความแตกต่างระหว่างในเขตและนอกเขตเทศบาล (Urban vs Rural Wage Gap):** ค่าจ้างในเขตเทศบาลสูงกว่านอกเขตอย่างต่อเนื่อง
9. **แนวโน้มประชากรผู้มีงานทำ (Employed Headcount Trend):** การเปลี่ยนแปลงจำนวนคนทำงาน 2555–2569

### 5.2 คำถามที่ตอบได้บางส่วน (Partially Supported)
1. **การเปรียบเทียบค่าจ้างรายไตรมาสในปี 2567–2568:** ตอบได้เฉพาะระดับรายปี (Annual) เนื่องจากไม่มีข้อมูลแยกไตรมาส 1–4
2. **การเปรียบเทียบภูมิภาคข้ามปี 2567 และ 2568:** ต้องคำนึงถึงการแยกภาคตะวันออกและภาคใต้ชายแดนในปี 2568
3. **Headcount จำแนกตามในเขต/นอกเขตเทศบาล:** ตอบไม่ได้ในภาพรวมทุกปี เพราะตาราง headcount เดิมไม่มีมิติพื้นที่

### 5.3 คำถามที่ตอบไม่ได้ (Cannot Be Answered — ข้อมูลไม่มีใน CSV)
1. **การจัดอันดับหรือโครงสร้างตามประเภทอุตสาหกรรม (Industry / Sector):** ไม่มีคอลัมน์ `industry` — **ห้ามสร้างชาร์ตอุตสาหกรรมเด็ดขาด**
2. **จำนวนผู้ว่างงานเป็นคน (Unemployment Headcount):** ไม่มีคอลัมน์จำนวนคนว่างงาน มีเพียงอัตราว่างงาน (%) — **ห้ามสร้างตัวเลขนับคนว่างงานโดยเด็ดขาด**
3. **ระดับการศึกษาของแรงงาน (Education Level):** ไม่มีคอลัมน์การศึกษา
4. **สถานะแรงงานในระบบ/นอกระบบ (Formal vs Informal Sector):** ไม่มีคอลัมน์จำแนกความคุ้มครอง
